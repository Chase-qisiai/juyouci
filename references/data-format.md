# 学习页输入格式

```json
{
  "title": "剧名 S01E01 · 词汇学习",
  "deck_id": "show-slug:S01E01:zh",
  "sources": ["真实来源 URL 或用户提供的字幕文件名称"],
  "note": "可选说明，例如材料不足，仅提取 32 条。",
  "cards": [
    {
      "term": "词汇或短语",
      "meaning": "本句语境中的中文释义",
      "ipa": "/音标/",
      "sentence": "实际来源中的英文原句",
      "translation": "原句的中文译文"
    }
  ]
}
```

所有五个词条字段都是非空纯文本，不能放 HTML 标记。标题与 deck_id 必填，sources 是字符串数组；cards 接受 1–500 条。不要自行设置词条 ID，脚本按词汇及原句生成稳定 ID。脚本以 textContent 渲染文本，安全嵌入引号、换行、中文及 `</script>` 等特殊字符。

输出路径应符合当前任务交付目录要求。数据 JSON 是生成时的中间文件，最终 HTML 无需它也能独立运行。

## 高亮与挖空

`targets` 可选，默认 `[term]`。实际词形与词头不同，或短语被宾语拆开时指定原句片段，如 `"targets":["turned","down"]`。不区分大小写，但必须是原句中的完整词/片段；所有匹配会一起高亮或挖空。避免用重复且含糊的片段。脚本拒绝找不到目标或重叠片段，并生成供浏览器使用的 UTF-16 `target_spans`，无需 AI 计算位置。
