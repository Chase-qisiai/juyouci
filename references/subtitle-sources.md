# 字幕来源备选

按目标语言和剧种选路线，不必逐站走完。站点覆盖和版权政策会变化，每次都要核对剧名、年份、季数、集数和原语言内容；只保存精选例句用于个人学习。

## 日剧 / 日语

1. **Jimaku**：<https://jimaku.cc/>。页面支持按文件名或 AniList URL 搜索日语字幕资源；优先用日文片名或罗马字片名搜索，再确认是否真的是 live-action 日剧和目标集。它的覆盖明显偏动画，因此日剧找不到时立即转下一站，不要反复刷新。
2. **Drama-Otaku**：<https://drama-otaku.com/>。这是日剧、电影和特别篇的 fansub / subtitle archive，部分内容可能需要注册或受站内权限限制。能读到日语字幕文件就使用；只能看到作品介绍或下载受限时，不把介绍页当台词。
3. **OpenSubtitles**：<https://www.opensubtitles.org/>。选择日语字幕语言，再按日文片名、年份、季数和集数筛选；同一集可能有多个视频版本，优先选择与集数和版本信息一致的 SRT/ASS。
4. **Kitsunekko**：<https://kitsunekko.net/>。可作为日语动画字幕备选，不作为日剧首选。下载到 `.srt/.ass` 后本地解析；站点目录和文件同步状况不稳定。
5. 搜索关键词：`日文片名 第1話 日本語字幕`、`日文片名 第01話 srt`、`日文片名 season 1 episode 1 Japanese subtitle`。必须同时使用日文标题和集数；只搜英文译名很容易得到英文翻译字幕。

**不要优先使用的旧路线：** `JpSubbers` 在多个近年检索结果中显示不可用或仅留下历史教程；除非本次搜索明确确认站点可访问并含目标文件，否则跳过。

## 韩剧 / 韩语

1. **GOM Lab 字幕资料库**：<https://www.gomlab.com/subtitle-home?lang=kr>。资料库提供韩语、英语、日语等语言筛选和标题搜索，适合先查韩语 SRT/SMI。搜索时优先输入韩文剧名，再按集数或视频版本核对；结果标题只有英文译名时要回到韩文名复查。
2. **OpenSubtitles**：<https://www.opensubtitles.org/>。把字幕语言设为 Korean/한국어，再按韩文剧名、年份、season/episode 过滤。多版本时以集数、分辨率/发行组和字幕行数判断是否对应目标视频。
3. **官方/平台字幕**：若用户提供 Netflix、Viki、TVING、Wavve 等页面或本地字幕文件，优先使用用户可访问的韩语原字幕；登录、地区限制或 DRM 导致无法读取时，不能假装已拿到台词，请用户贴字幕文本或上传 `.srt/.vtt/.ass/.smi`。
4. 搜索关键词：`韩文片名 1화 한국어 자막`、`韩文片名 2화 srt`、`韩文片名 시즌 1 자막`、`韩文片名 Korean subtitle SRT`。韩剧标题必须同时尝试韩文原名、官方英文名和罗马字名。

## 通用兜底

- **OpenSubtitles**：适用于多语言影视字幕；必须选择目标语言，不能把英文翻译字幕当作日语/韩语原文。
- 已知站点的单集正文可以通过 `https://r.jina.ai/` 预处理，但先确认原页面真的含连续对话；代理返回导航页、验证页或错误页时立即放弃该候选。
- 用户提供字幕文件时直接解析，不再联网。支持 `.srt`、`.vtt`、`.ass`、`.ssa`、`.smi` 和纯文本台词；先去时间码、标签和重复行，再保留原语言对白。
- 日本脚本数据库 <https://db.nkac.or.jp/> 主要提供脚本书目信息，原始脚本不公开；只能用来核对作品/编剧信息，不能当作可直接提取的台词来源。

## 成功判断与止损

成功必须同时满足：

1. 页面或文件身份匹配剧名、年份、季数和集数；
2. 内容是目标语言的连续对白，或字幕文件包含时间码和对白行；
3. 能从中抽出多条不重复的完整原句。

HTTP 200、页面字数多、搜索摘要或剧情简介都不算成功。请求使用 `--connect-timeout 8 --max-time 20 -fL`；每个站点最多换一次搜索词，最多尝试三类来源。所有下载和引用都遵守站点条款与版权边界，不下载整集视频，不绕过登录、付费或地区访问控制。
